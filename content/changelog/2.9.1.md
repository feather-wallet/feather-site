#### Notice

The built-in Tor daemon shipped with the previous Feather release was deprecated. Users who are unable to connect to a node are advised to update to this version, or to install Tor systemwide, or open Tor Browser and change Feather's Tor proxy port to 9150. Or turn off Tor in Feather.

#### Fixes

- wizard: manually changing the subaddress lookahead now works when restoring 25 word seeds
- various minor bug fixes

#### Deprecations

- Send: the Fiat column was removed

  I have been unable to reliably obtain historical pricing data. I may reintroduce this at a later date.

- the Mining and Bounties plugin were removed

  The websocket service is being phased out. Functionality that depends on it will gradually be removed. Real time fiat / crypto price conversion will remain supported.

- support for ARM32 Linux was removed

  This may affect you if you're running Feather on a Raspberry PI with a 32-bit OS. Most Raspberry PI models are capable of running a 64-bit OS, so consider upgrading.

- the Windows release is no longer codesigned

  I pursued codesigning under the misguided assumption that improving SmartScreen reputation would help to reduce AV false positives. 
  This didn't help, if anything the AV situation is worse now. Codesigning adds too much complexity to the reproducible builds process. Removing codesigning does not affect release security; codesigning was never a replacement for verifying GPG signatures against the release signing key. I have given up on finding workarounds to appease AV and do not want to waste more time on it.

- minimum macOS version is now 14 (was 12)

#### Maintenance

- Monero updated to v0.18.5.1
- Qt updated to v6.11.1
- Tor updated to 0.4.9.11
- Linux and Windows releases are now built with GCC 15.2 (up from 12.4)
- macOS releases are now built with Clang 22 (up from 18)
